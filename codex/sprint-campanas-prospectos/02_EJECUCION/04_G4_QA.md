# G4 — QA, seguridad, migraciones y consistencia de contrato

**Entrada:** código candidato versionado y database de prueba desechable.  
**Salida:** matriz 32 pruebas y AC con evidencia por SHA (no todos los escenarios son ejecutables solo por backend).

### Categorías mínimas

- Unitarias: normalización/candidatos, validación motivos, cambios de etapa, correcciones de bitácora, filtros y agregaciones.
- HTTP/E2E: roles, JWT, tenant seleccionado, 400/401/403/404/409, wrappers, paginación, OpenAPI/Swagger, deserialización compatible.
- PostgreSQL 16 (o versión exacta compatible del proyecto): transacciones, unique/concurrencia para identidad fuerte, import preview/confirm y rollback, migraciones legacy sintéticas y backfill sin falsear historial.
- Regresión: import V1 5MB / 1000 / 2000 por celda / referencia 15 min, clasificación, acción por fila, límites, CREATE/LINK/UPDATE/SKIP, no cambio global implícito; CRUD legacy; estado de Jobs sin Service.
- Seguridad: dos tenants homónimos, cambios de campaña, IDs cruzados, selección de responsables del otro tenant, fuga de contadores, metadatos sensibles, logs anonimizados.
- Contract parity: YAML objetivo + Swagger servido + controladores + SDK de referencia del cliente, con DRIFT documentado y mitigación; no actualizar Flutter en esta fase.
- Rendimiento: dataset sintético grande y mediciones aproximadas reales, sin inventar SLA; explain/indexes si el patrón lo amerita.

### Evidencias

Actualizar `03_CALIDAD/MATRIZ_AC_Y_TESTS.md` **mediante copia o un reporte de estado**, no falsear el original; capturar comando, timestamp, SHA, dataset, resultados y limitaciones en `05_EVIDENCIAS/G4/MATRIZ_QA.md`. Adjuntar logs sanitizados. `T32` E2E Flutter real corresponde al handoff/André: backend prepara fixtures/contrato, no declara PASS de T32 antes de ejecutarlo en Flutter.

### Regla no negociable

No usar bases de datos de producción para probar migración, no imprimir CSV reales/JWT/credenciales en logs, no hacer migrate deploy en infra remota y no afirmar recuperación rollback si no se ensayó de manera segura.
